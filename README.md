# 🌐 Personal Portfolio Website

A modern multi-page Personal Portfolio Website built using **Python Flask**, **HTML5**, and **CSS3**. The website follows semantic HTML structure and is designed to be responsive, accessible, and easy to customize.

---

## 📌 Features

- 🏠 Home Page
- 👤 About Page
- 💼 Projects Page
- 📞 Contact Page
- Responsive Design
- Semantic HTML5
- CSS3 Styling
- Flask Backend
- Accessible Navigation
- Profile Image Support
- Contact Form
- Professional Portfolio Layout

---

## 🛠 Technologies Used

- Python 3.x
- Flask
- HTML5
- CSS3
- Jinja2 Templates

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/portfolio.git
```

Move into the project directory

```bash
cd portfolio
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Run the Application

```bash
python app.py
```

The application will start on

```
http://127.0.0.1:5000
```

Open the above URL in your browser.
